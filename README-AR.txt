CashTop Ready v8
================

النسخة تعمل مباشرة مع نفس Turso وBunny المدمجين في direct-cloud.js.

الجديد في v8:
- إعادة تصميم قائمة أرشيف النقدية بالكامل لمنع تداخل التاريخ والرصيد.
- إلغاء اقتراحات الاسم عند إضافة عميل أو مورد.
- إصلاح حقل Add note مع كيبورد Android وحفظ الملاحظة الفعلية.
- زر مشاركة الحساب ينسخ رابطاً عاماً خاصاً بالعميل/المورد.
- الرابط العام القصير يكون بالشكل: https://your-domain/?c=XXXXXXXXXXX
- مفتاح الرابط فريد على مستوى جميع الشركات.
- صفحة c.html تعرض معاملات الحساب فقط بدون تسجيل دخول وبدون عناصر دفع.
- نقل معاملات العميل/المورد للأرشيف: معاملة واحدة أو تحديد الكل.
- فتح أرشيف الحساب من أعلى صفحة الحساب.
- إرجاع أو حذف معاملات أرشيف العملاء/الموردين.
- إرجاع أو حذف معاملات أرشيف دفتر النقدية.
- الصور تبقى مرتبطة بالمعاملة وتستمر استراتيجية الضغط إلى 50KB والرفع إلى Bunny.
- أرشيف العملاء/الموردين يُحمّل على صفحات عند الحاجة ولا يدخل في sync pull العام.

ملاحظة أمنية:
هذه نسخة اتصال مباشر كما طلبت؛ مفاتيح Turso/Bunny موجودة في JavaScript ويمكن فحصها من المتصفح عند نشر الموقع للعامة.
